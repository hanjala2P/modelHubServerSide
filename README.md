
# Model Hub - Backend Server

This is the backend server repository for Model Hub, handling database operations, authentication verification via Firebase Admin, and CRUD functionality.

## Tech Stack

* Node.js
* Express.js
* MongoDB & Mongoose
* Firebase Admin SDK
* CORS & Dotenv

## Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/hanjala2P/modelHubServerSide.git

```


2. Navigate to the project directory:
```bash
cd modelHubServerSide

```


3. Install dependencies:
```bash
npm install

```


4. Create a `.env` file in the root directory and add your environment variables:
```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
CLIENT_URL=your_frontend_url

```


5. Start the server:
```bash
npm run dev

```
